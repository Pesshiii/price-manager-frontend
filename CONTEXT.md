# Глоссарий предметной области — Price Manager Frontend

## Выгрузка (SupplierFeed)

**Выгрузка** — сессия приёма периодического файла от поставщика, содержащего изменяемые данные о товарах (цены, остатки и т.д.). Не путать с **Импортом** (`ImportJob`) — тот обновляет постоянные характеристики товара. Жизненный цикл: `draft → processing → matched | partial → done | error`. Переход `partial → done` происходит автоматически, когда все записи MatchQueue разобраны.

**Конфигурация выгрузки (FeedMapping)** — постоянная настройка на одного поставщика: какая колонка является `supplier_sku`, какие — identity-поля (идентификация для эмбеддинга), какие — переменные поля (цена, остаток и т.д.), а также порог авто-матчинга. Создаётся один раз, переиспользуется для всех последующих выгрузок этого поставщика.

**Identity-поля** — колонки строки выгрузки, используемые для построения эмбеддинга при матчинге. Не путать с `supplier_sku` — тот является ключом SupplierLink, identity-поля идут только в эмбеддинг.

**Переменные поля** — колонки строки выгрузки с изменяемыми данными (цена, остаток, склад и т.д.). Сохраняются в `SupplierFeedEntry.data`.

---

## Очередь матчинга (MatchQueue)

**MatchQueue** — множество строк выгрузки, для которых автоматический матчинг не дал результата выше порога. Не отдельная модель — это фильтр `SupplierFeedEntry` с `product=None` и `skipped=False`. Разбирается пользователем вручную.

**SupplierFeedEntry** — одна строка из загруженного файла поставщика в рамках сессии выгрузки. До матчинга `product = null`. Содержит переменные поля в `data` и топ-N кандидатов на матчинг в `match_candidates`.

**Кандидат на матчинг** — товар из каталога с косинусным скором сходства, предложенный алгоритмом для конкретной строки выгрузки. Хранится в `SupplierFeedEntry.match_candidates: [{product_id, score, name}]`.

**Resolve** — действие пользователя над записью MatchQueue: подтвердить кандидата (`product_id`) или пометить как пропущенную (`skipped=true`). После resolve создаётся или обновляется SupplierLink.

---

## Связи (SupplierLink)

**SupplierLink** — постоянная подтверждённая связь между артикулом поставщика (`supplier_sku`) и товаром в каталоге (`Product`). Ключ: `(supplier, supplier_sku)`. Создаётся при первом подтверждении матчинга. В последующих выгрузках используется для мгновенного авто-матча без повторного эмбеддинга.

---

## Поставщик (Supplier)

**Поставщик (Supplier)** — контрагент, предоставляющий выгрузки. Простая сущность: `{id, name}`. Управляется через `/api/suppliers/`. В интерфейсе используется как справочник для селекторов; отдельного CRUD-экрана нет.
